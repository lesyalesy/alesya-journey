# Alesya — Journey to Product

A visual career story designed to complement, not duplicate, a traditional CV.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push this folder to a GitHub repository and import it into Vercel as a Vite project.

Build command: `npm run build`  
Output directory: `dist`

## Before publishing

The `From Chat to Plan` button currently points to:
`https://from-chat-to-plan.vercel.app/`

If Vercel gave your product case study a different URL, replace that URL in `src/main.jsx`.


## Motion edition
Adds floating ambient shapes, one-time hero shake, hover reactions, subtle phone/chat motion, and reduced-motion accessibility.
